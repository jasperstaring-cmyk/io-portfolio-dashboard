Portfolio & Event

Open the configurator via ⚙ in the operator bar. Go to Portfolio & Event. The sidebar shows seven sections — click any to jump directly. Set this once per event.

↑ Sidebar navigation on the left. An orange dot means that section's weights don't add up to 100% yet.
Event nameShown in the header on the presentation screen.
Default languageEN / NL / FR / DE. Determines which language loads first.
Presentation sizeScales all chart text simultaneously. 1.00 = laptop · 1.35 = auditorium · 1.50 = large screen. Apply and check on the actual screen.

Name, risk profile (Defensive / Balanced / Growth / Dynamic), and base currency. This is the foundation — all sessions inherit from this portfolio unless a custom starting point is configured.

Per asset class: Current %, Target %, Min %, Max %. Both Current and Target must add up to 100%. The total badge shows the current sum — orange if off.

⚠
Min and Max define the policy bandwidth visible in the chart. A realistic range (e.g. ±10pp) makes the visualisation more meaningful.

Weight per implementation category (Active Management, Passive ETF, Individual Securities). Must add up to 100%. Also set the Weighted avg. TER (%).

ESG Score0–10. Shown on the gauge in the ESG chart.
Carbon Risk ScoreDisplayed as a KPI next to the gauge.
SFDR DistributionArticle 9 / 8 / 6 percentages. Must add up to 100%.

Key metrics

YTD %, 1Y %, 3Y Ann. %, Benchmark %, Volatility %, Max Drawdown %.

Time series

Click + Add data point per period. Each row: Label (month, quarter, year — free text), Portfolio value, Benchmark value. First row = index 100.

Tip
Quarterly data is faster to enter and still produces a clear chart. Monthly data gives a smoother line.

Both sections shown side by side. Weight per sector and per currency. Both must add up to 100%.

By default, every session inherits the event portfolio. Toggle Own starting point to override specific allocation weights for this session only. Leave fields blank to inherit from the event portfolio.

Fill in only the allocations that change. Leave others blank to keep the base value. The delta column shows the difference in percentage points.

⚠
A delta of less than 5pp is barely visible on stage. Aim for at least 5–10pp difference per category for a clear visual contrast.

Before the event — Configurator

Apply & Save

Three buttons in the top right of the configurator control what happens to your changes.

✓ ApplyUpdates the live dashboard immediately. The configurator stays open. Use this to preview changes on the presentation screen while configuring.
+ Save to registrySaves the configuration permanently. Persists after browser refresh. Always save before closing.
Discard changesReverts all changes back to the last saved state.
Tip
Set the presentation size (typography scale) while the presentation screen is active — so you can verify labels are readable at the actual distance.

Recommended workflow

Configure Portfolio & Event completely. Apply to preview.
Set up all use cases in order. Apply after each session to verify it looks correct.
Check all totals — no orange dots in the sidebar.
Save to registry. Close the configurator.
Run through all sessions once from the operator bar to verify the flow.

On the day

Navigating sessions

Switching between sessions is done with the arrow buttons. Everything is prepared — navigating is all that's needed.

Use the ← → arrow buttons to move to the next or previous session.
The screen name on the left confirms which session is active.
Switching sessions automatically resets Compare to OFF.
Tip
Navigate to the correct session before the speaker begins — the chart loads immediately when you arrive.

Click interactions in charts

Asset ClassClick a pie segment → it explodes and shows the policy status (Within policy / Off target / Outside range).
ESGClick an SFDR card → shows a plain-language explanation of that article in practice.
SectorClick a top-3 card → shows context for the meta-category.
ImplementationClick a segment → highlights it, dims the others, shows the sub-description.

Click the same element again to return to the default state.

On the day

Compare

Reveal an alternative portfolio state live. One click — bars shift, delta indicators appear. Only available for sessions where Compare is configured.

↑ Compare active — amber badge in the operator bar, delta indicators in green (+) and red (−) per category.
The Compare button is bright (not dimmed) if a comparison is configured for this session.
Click Compare. The chart animates — bars shift, delta indicators appear.
The comparison label appears in the operator bar — e.g. "Full Article 9" or "Reduced US exposure".
Click Compare again to return to the base state.
Tip
Agree on a signal with the speaker before the session — so Compare activates at exactly the right moment in the conversation.
On the day

Explore mode

Live sliders for audience interaction. Only available for sessions where Explore is configured.

↑ Explore mode active — green accent line, slider panel at the bottom, total indicator shows 100% ✓.
Click Explore. The operator bar gets a green accent line. The slider panel opens automatically.
Move the sliders. The chart updates immediately.
Use the toggle tab (▼ Hide / ▲ Show) to collapse the slider panel — the chart becomes fully visible.
Click ← Back to exit. The session returns to exactly the previous state.
⚠
Explore does not save values. Exiting restores the previous portfolio state exactly.

Total indicator

100% ✓Allocation adds up — the chart is valid.
98% !Under 100% — sliders need to go up.
103% !Over 100% — sliders need to go down.

During your session

For speakers & partners

The dashboard is configured before you arrive. Your role is to bring the expertise — the instrument does the rest.

💬
Someone else navigates

A dedicated person handles the dashboard during your session — activating Compare and Explore at the right moments based on your cues or the conversation.

🎛
Or you navigate yourself

If you prefer full control, you can operate the dashboard yourself. Compare and Explore are single clicks — no technical knowledge required.

What is configured for your session

Chart dimensionThe visualisation matched to your topic.
Compare scenarioThe alternative portfolio state that reveals when Compare is activated.
Explore modeOptional — live sliders for audience interaction.
Performance viewOptional — time-series showing the historical impact of your topic.

Using Explore mode in your session

Explore is for sessions where you want the audience to actively engage with the portfolio — shifting allocations in response to your questions.

The slider panel opens above the operator bar. The chart responds in real time to any slider movement.
The panel can be collapsed (▼ Hide) so the chart is fully visible during the moment of impact.
The total indicator confirms whether the allocation still adds up to 100%.
Exiting Explore restores the previous state exactly — nothing is saved.
Tip
A short briefing before the event is enough to align on the one or two moments where a cue makes sense — no technical preparation required.

Ideas for your session

"What would you do?"Start from the current portfolio. Ask the audience to collectively decide on one change. Move the slider live.
The revealBuild your argument, then activate Compare. "This is what a full Article 9 allocation would look like."
The stress testTake a slider to the extreme — show the consequence of a maximum shift.
The trade-offShow that moving one slider forces another down. The total indicator makes this concrete.
